A growing collection of specialized AI skills for animation, storytelling, trading research, and creative workflows.

Parvat is an open-source project focused on developing useful Claude Skills that make AI-powered workflows easier, faster, and more accessible.

Our goal is to help creators, developers, and researchers accomplish complex tasks through specialized AI instructions and workflows.

* Scene planning and sequencing
* Animation style direction

* Visual storytelling workflows
